## 说明

本仓库收录 **1.96 寸 410×502 AMOLED** 显示模组资料。同一规格下可能有多个版本，驱动芯片、触摸方案、接口等细节以 `versions/` 下各版本自己的 README 为准。

**根目录 README 为导航页**。下表可快速浏览各版本；点击「完整资料」进入 `versions/` 下对应**料号文件夹**（产品页、规格书等资料均在该目录内）。示例工程不区分版本，统一放在仓库根目录的 [`examples/`](./examples/) 中，见下文「示例工程」一节。

规格标识（仓库名）：`display-amoled-1.96inch-410x502`
